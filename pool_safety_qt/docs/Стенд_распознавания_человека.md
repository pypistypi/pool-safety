# Тест детекции людей

Это отдельное окно. Исходные файлы `pool_safety_qt` не изменяются.

## Запуск

1. Установить Python 3.11+.
2. В этой папке выполнить:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\demo_app.py
```

Файл модели должен находиться в `models\yolov5n.onnx`. Это лёгкая ONNX-модель YOLOv5, обученная на COCO; класс `person` имеет индекс 0.

Окно поддерживает видеофайл, изображение и подключённые камеры. При запуске оно получает список камер Windows через DirectShow и показывает их системные имена; выберите нужную камеру в выпадающем списке, нажмите «Открыть выбранную камеру», затем «Запустить». Кнопка «Обновить камеры» перечитывает список после подключения или отключения устройств. Вычисления выполняются в `QThread`, используется только последний актуальный кадр, интервал детекции задаётся от 80 мс. OpenCV ограничивается двумя потоками CPU, очередь кадров не накапливается.

## Интеграция в C++-проект

Граница интеграции находится в `PersonDetector.detect(frame)`: на вход подаётся один BGR-кадр, на выходе — список прямоугольников и confidence. Сигнал `VideoWorker.presence_detected(count)` является аналогом требуемого Сигнала 1. Для четырёх камер создаются четыре экземпляра рабочего объекта или один координатор с четырьмя последними кадрами; UI получает только готовые результаты через Qt-сигналы.

В production рекомендуется вынести inference в отдельный процесс, собрав приложение PyInstaller вместе с Python runtime, библиотеками и файлом `models\yolov5n.onnx`. Для текущего теста Python-версия намеренно изолирована и не требует правок основного C++-каркаса.
