# Наблюдение за бассейном

Видеонаблюдение за зоной бассейна: находит людей в кадре, распознаёт опасные
положения и зовёт оператора посмотреть. Программа для компьютера поста
наблюдения + приложение для телефона с уведомлениями и живым видео.

Система не ставит диагноз «человек тонет» — надёжной модели распознавания
утопления не существует. Она делает выполнимое: не даёт человеку остаться
незамеченным. Работает полностью локально, без интернета. Лица не
распознаются — только положение тела.

## Установка

**Компьютер.** Запустите скачанный установщик, следуйте инструкциям.
При первом запуске откройте «Настройки → Объект» и заполните адрес и телефоны
экстренных служб — они попадут в карточку тревоги.

**Телефон.** Скачайте APK и откройте его — Android спросит разрешение на
установку из неизвестного источника (укажите браузер или файловый менеджер).
После установки откройте приложение, разрешите уведомления и нажмите
«Найти компьютер» — телефон и компьютер должны быть в одной сети Wi-Fi.

Уходя с телефоном за пределы этой сети, нажмите «Отключиться» рядом со
строкой связи — иначе приложение будет бесконечно и безрезультатно пытаться
достучаться до поста. «Подключиться» возвращает всё как было.

Приложение умеет само проверять, вышла ли новая версия (раз в сутки при
открытии, можно выключить в настройках) — единственное обращение в интернет
во всём приложении; связь с постом наблюдения остаётся только локальной.

## Подключение IP-камеры

В программе: панель → «Подключить IP-камеру…» → «Начать поиск». Найденную
камеру можно подключить сразу; если камера не находится — введите адрес
вручную (путь потока смотрите в настройках самой камеры).

## Сборка из исходного кода

Нужны Qt 6.11 (MinGW 64), CMake, Ninja, JDK 17 и Android SDK (`cmdline-tools`
+ Gradle) для мобильного приложения.

```powershell
# Программа для ПК: собирает, прогоняет 66 проверок, пакует установщик
powershell -ExecutionPolicy Bypass -File pool_safety_qt\deploy\build_release.ps1

# Приложение для Android
powershell -ExecutionPolicy Bypass -File pool_safety_android\deploy\build_apk.ps1 release
```
