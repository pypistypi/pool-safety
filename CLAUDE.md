# Правила работы над проектом «Наблюдение за бассейном»

**Полный справочник — в `ПРОЕКТ.md` рядом с этим файлом. Прочитать его до
начала работы.** Там структура папок, устройство кода, все измерения, разбор
ложных срабатываний и текущие задачи.

Кратко о главном. Код и выпуски — на github.com/pypistypi/pool-safety.

## Что за проект

Программа видеонаблюдения за бассейном гостиницы (Красная Поляна, Сочи).
C++/Qt 6, папка `pool_safety_qt`. Помещение арендованное — работы в чаше
невозможны.

Система **не ставит диагноз «человек тонет»**, а **не даёт человеку остаться
незамеченным**: зовёт оператора посмотреть. Формулировки в интерфейсе и
документах выверены — не менять на «распознаёт утопление».

## Жёсткие ограничения

- Лица не распознаются, только положение тела (152-ФЗ).
- Всё считается локально, без интернета и облаков.
- Изображение не сохраняется.
- Лицензии только permissive: YOLOX и RTMPose (Apache 2.0), Qt (LGPL),
  ONNX Runtime (MIT). Ultralytics AGPL-3.0 для гостиницы неприемлема.

## Грабли, на которые уже наступали

1. **Каталог сборки не должен содержать кириллицу** — `moc` в таком пути не
   работает. `deploy\build_release.ps1` собирает во временной папке.
2. **Скрипты `.ps1` — только UTF-8 с BOM**, иначе PowerShell 5.1 ломает русский.
3. **Bash-heredoc здесь ненадёжен** — патчи писать файлом через Write, затем
   запускать `python файл.py`.
4. **Тесты выводят результат только с** `-o файл,txt`.
5. **Русские ключи JSON читать через `QString::fromUtf8`**, не `QLatin1String`.

## Как работать

- Всё по-русски: интерфейс, комментарии, документы, ответы. Орфография строгая,
  с буквой ё.
- Проверять измерением, а не утверждением: нагрузку — счётчиком процессорного
  времени, отрисовку — снимком экрана, распознавание — на настоящих кадрах.
- Ложная тревога дороже пропущенной, если она частая: за смену она приучает
  оператора не верить сирене.
- Признак, не проверенный на настоящем случае, не получает права на сирену.
- Каждое исправление ложного срабатывания закреплять проверкой в
  `pool_safety_qt/tests/test_core.cpp`. Сейчас их 66, все зелёные.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File deploy\build_release.ps1              # программа
powershell -ExecutionPolicy Bypass -File pool_safety_android\deploy\build_apk.ps1 release
```

Собирает, прогоняет проверки (при провале поставку не собирает), раскладывает
`dist\PoolSafety`, пакует архив и делает установщик.

## Ближайшие задачи

1. **Проверить связку на настоящем телефоне** — пока только эмулятор.
2. **Настроить пороги под реальную сцену** — нужны записи с бассейна.
3. **Калибровать признак ребёнка** — нужна съёмка детей на объекте.

Версия задаётся ТОЛЬКО в `pool_safety_qt/src/core/Version.h`. Скрипт сборки
читает её оттуда и передаёт установщику — руками в `.iss` не править.
